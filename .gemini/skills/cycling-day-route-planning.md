# Skill：單車環島每日路線規劃文件產生

## 📌 目的

根據 `index.md` 的 10 天環島總覽，為每一天產生兩份檔案：
1. **`dayN.md`**：詳細路線行程 Markdown 文件
2. **`dayN_mymap.csv`**：Google My Maps 匯入用的 CSV 檔案

---

## 📁 目錄結構

每天的檔案放在各自的 `dayN/` 資料夾中：

```
CyclingTW/
├── index.md                    ← 10 天環島總覽
├── day1/
│   ├── day1.md                 ← Day 1 路線行程
│   └── day1_mymap.csv          ← Day 1 Google My Maps CSV
├── day2/
│   ├── day2.md
│   └── day2_mymap.csv
├── ...
└── day10/
    ├── day10.md
    └── day10_mymap.csv
```

---

## 📂 參考檔案

| 檔案 | 用途 |
|:---|:---|
| `index.md` | 10 天環島總覽，包含每日出發地/目的地/距離/路線/景點 |
| `day1/day1.md` | 第一天的完整範本（結構模板） |
| `day1/day1_mymap.csv` | 第一天的 Google My Maps CSV 範本 |

---

## 📝 dayN.md 文件結構

依照以下順序撰寫，每個段落之間用 `---` 分隔線隔開：

### 1. 標題
```markdown
# Day N：出發地 ➔ 目的地 (路線特色副標題)
```

### 2. 📍 路線總覽
```markdown
## 📍 路線總覽
* **出發地**：XXX
* **目的地**：XXX
* **總距離**：約 XX - XX 公里
* **總爬升**：描述爬升狀況
* **主要路線**：路線A ➔ 路線B ➔ 路線C
```

### 3. 🌍 Google Maps 導航連結
- 使用 Google Maps Directions API 格式
- URL 格式：`https://www.google.com/maps/dir/?api=1&origin=起點&destination=終點&waypoints=途經點1|途經點2&travelmode=bicycling`
- 中文地名需要 URL encode
- waypoints 用 `|` 分隔，最多 10 個

### 4. 🐟 魚骨圖 (Ishikawa Diagram)
- 使用 `ishikawa-beta` 語法（參考 `mermaid-ishikawa-fishbone.md` skill）
- 魚頭：`Day N 完騎 目的地 距離`
- 上方主骨：各段路況資訊
- 下方主骨：各段休息補給（用 ☕️ 標記）
- **倒序排列**（最後一段寫在程式碼最前面）
- Emoji 對照：

| Emoji | 用途 |
|:---:|:---|
| ☕️ | 休息站分類標題 |
| 🥤 | 便利商店/補給站 |
| 🍔 | 用餐點 |
| 🏞️ | 拍照/景點 |
| 🚻 | 公廁 |
| 🏠 | 住宿 |
| ⚠️ | 注意事項/警告 |
| 🚎 | 交通/轉乘 |

### 5. 🕒 建議行程與時間配速
- 將全程分成 3~5 段
- 每段包含：
  - 段落副標題（含起訖與特色）
  - **距離**
  - **路況**描述
  - **景點/休息補給**：詳細列出每個停靠點的便利商店名稱、設施、推薦原因

### 6. 💡 騎乘注意事項
- 3~5 項重點注意事項
- 包含：氣候/風向、補給空窗、路況危險、撤退方案等
- 撤退方案需列出具體的火車站或替代住宿點與距離

## 📊 dayN_mymap.csv 檔案格式

### CSV 欄位定義

```csv
景點名稱,地點搜尋關鍵字,順序,類型,備註說明
```

| 欄位 | 說明 | 範例 |
|:---|:---|:---|
| 景點名稱 | 顯示在地圖上的標記名稱 | `蘆洲柳堤公園` |
| 地點搜尋關鍵字 | Google Maps 搜尋用的精確關鍵字 | `新北市蘆洲區柳堤公園` |
| 順序 | 沿途順序編號（從 1 開始） | `1` |
| 類型 | 分類標籤 | 見下方類型表 |
| 備註說明 | 補充資訊（時間、設施、推薦原因） | `早上 07:00 出發，河濱出發點` |

### 類型分類

| 類型值 | 說明 |
|:---|:---|
| `起終點` | 當日出發點或終點 |
| `景點` | 觀光景點、拍照打卡點 |
| `便利商店` | 7-11、全家、萊爾富等 |
| `加油站` | 中油等，可借廁所 |
| `餐廳大休` | 午餐或長時間休息的用餐地點 |
| `綜合休息站` | 有多種設施的複合休息站 |
| `公共設施` | 公廁、飲水機等公共設施 |

### 地點搜尋關鍵字撰寫原則

1. **便利商店**：使用「品牌 + 門市名稱」，例如 `7-ELEVEN 觀湖門市`
2. **加油站**：使用「台灣中油 + 站名」，例如 `台灣中油大園站`
3. **景點/漁港**：使用「縣市 + 景點名」，例如 `桃園永安漁港`
4. **公共設施**：使用完整地址或附近知名地標搜尋
5. **避免模糊關鍵字**：不要只寫「加油站」或「7-11」，要加上具體門市/站名

### CSV 範例

```csv
景點名稱,地點搜尋關鍵字,順序,類型,備註說明
蘆洲柳堤公園,新北市蘆洲區柳堤公園,1,起終點,早上 07:00 出發，河濱出發點
八里左岸,新北市八里左岸自行車道,2,景點,經過八里渡船頭自行車道
7-11 八里門市,7-ELEVEN 八里門市,3,便利商店,離開八里前補充水分 (八里渡船頭旁)
```

## 🔧 產生流程 Checklist

1. [ ] 從 `index.md` 取得該日的出發地、目的地、距離、路線、景點
2. [ ] 使用 Google Maps 工具查詢路線，確認實際道路與距離
3. [ ] 沿路線搜尋補給點（便利商店、加油站、公廁）
4. [ ] 將路線分成 3~5 段，每段約 20~40 km
5. [ ] 撰寫 `dayN.md`，依照上方結構填入內容
6. [ ] 製作魚骨圖（參照 `mermaid-ishikawa-fishbone.md` skill）
7. [ ] 產生 `dayN_mymap.csv`，確保關鍵字精確
8. [ ] 用 Google Maps 工具驗證各停靠點的位置是否在路線上
9. [ ] 確認補給空窗區段（超過 20km 無補給）並特別標註

---

## ⚠️ 注意事項

- **補給點驗證**：使用 `mcp_google-maps_maps_search_places` 工具搜尋確認便利商店/加油站是否存在且營業中
- **路線順序**：CSV 中的順序必須與實際騎乘方向一致
- **距離估算**：使用 `mcp_google-maps_maps_directions` 工具以 `bicycling` 模式計算實際騎乘距離
- **撤退方案**：每日至少標註 2~3 個可中途撤退搭火車的車站
